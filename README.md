# Max Healthcare Equipment x Silverchain referrer portal

Tender demonstration of the referrer portal Max Healthcare Equipment proposes for Silverchain care partners and support coordinators. This repository holds only the Silverchain portal and its access page. Nothing else from the Max website is published here.

| Path | What it is |
| --- | --- |
| `index.html` | Access page |
| `portal/` | The referrer portal (single page, runs in the browser, demo data in local storage) |
| `accessibility/` | WCAG 2.1 AA conformance report, HTML and PDF |
| `images/`, `fonts/` | Only the assets the portal uses |

Published with GitHub Pages straight from the `main` branch.

Run locally: `python -m http.server 8080`, then open http://localhost:8080/.

"Reset demo" in the portal header restores the starting data.
